# 痛点搜集器 Pain Radar

从用户评论、聊天记录、论坛帖子中，发现真实市场痛点和潜在产品机会的工具。

粘贴评论 → 识别真实痛点 → 提取用户/场景/付费信号 → 自动聚类 → 生成带评分的市场机会卡片 → 查看原始证据与产品建议。

**首次打开即有完整 Demo 数据**（46 条真实感评论、8 个机会簇、7 个高分机会），不需要配置任何 API Key 或外部服务。

## 技术栈

- **Next.js 16**（App Router + Turbopack）+ **TypeScript** + **React 19**
- **Tailwind CSS 4**（浅色默认，支持深色模式切换）
- **SQLite + Prisma 7**（本地文件数据库 `prisma/dev.db`，零外部依赖；Schema 可平滑迁移 PostgreSQL）
- **AI Provider 层**：Anthropic API / OpenAI API / 本地规则分析器（自动降级，永不失败）

## 快速启动

```bash
npm install
npm run dev        # 会自动执行 prisma db push 建表
```

打开 http://localhost:3000 —— 首页发现数据库为空时会自动写入 Demo 数据。

手动初始化（可选）：

```bash
npm run db:push    # 创建/同步数据库表
npm run db:seed    # 重置并写入 Demo 数据（等同页面上的"重置 Demo 数据"按钮）
```

## 页面导航

| 路径 | 页面 | 说明 |
|---|---|---|
| `/` | 首页 Dashboard | 指标卡、7 天趋势图、高频痛点词、Top 6 机会、最近导入 |
| `/import` | 导入分析 | 选平台/语言 → 粘贴评论（每行一条）→ 开始分析；含"一键导入示例" |
| `/radar` | 机会雷达 | 全部机会卡片；按行业/用户/痛点类型/平台/分数/付费信号/AI 适配筛选 |
| `/opportunity/[id]` | 机会详情 | 总分、六维评分解释、产品建议、全部原始评论证据 |
| `/opportunity/[id]/report` | 研究报告 | 模板 + 已有数据生成的完整 Markdown 报告，可一键复制 |

## 如何导入评论

1. 首页点「导入评论并分析」（或直接访问 `/import`）
2. 选择来源平台和语言，粘贴评论（每行一条，最多 200 条/次）
3. 点「开始分析」→ 每条评论展示是否痛点、类型、用户、场景、四项 0-10 评分、AI 总结、推荐方向
4. 结果自动保存到数据库并触发重新聚类，首页与机会雷达同步更新，刷新浏览器数据仍在

## 配置 AI Key（可选）

复制 `.env.example` 为 `.env`，填入任意一个：

```bash
ANTHROPIC_API_KEY="sk-ant-..."   # 优先使用（模型默认 claude-opus-4-8，可用 ANTHROPIC_MODEL 覆盖）
OPENAI_API_KEY="sk-..."          # 次选（默认 gpt-4o-mini，可用 OPENAI_MODEL 覆盖）
```

**没有 Key 时**：系统使用内置的规则分析器（`src/lib/analyzer/rules.ts`），基于强痛点词（"太麻烦""手动""浪费时间""愿意付费""有没有工具"等中英文关键词）+ 8 个预置机会方向的加权关键词匹配，输出与 AI 完全相同的结构化结果。AI 调用失败时也会自动回退到规则分析器，导入永不失败。

## 评分公式（总分 100）

痛点强度 25 + 出现频率 20 + 付费信号 15 + 软件可解决性 15 + AI 自动化适配 15 + 现有方案不足 10。
≥70 为高价值，50-69 值得观察，<50 低优先级。每个机会详情页展示逐维度的评分解释。

## 聚类逻辑

轻量可解释聚类：分析器为每条评论输出 `topicKey`（命中 8 个预置机会方向之一），同 key 的评论聚为一簇；未命中主题的痛点按 `painType + targetUser` 聚合。每次导入后全量重算所有簇的评分与趋势（上升/平稳/新出现）。接入 Embedding API 可作为后续增强。

## 哪些是 Demo 数据

`src/lib/demo-data.ts` 里的 46 条评论（覆盖 11 个平台、10 类用户、8 个机会方向）及其作者、时间均为构造的演示数据；由它们聚成的 8 个初始机会卡片同样属于演示内容。你导入的评论与由此产生/更新的机会是真实数据。「重置 Demo 数据」会清空全部数据并恢复初始演示状态。

## 完整流程自测

1. `npm install && npm run dev`，打开首页 → 应看到完整 Demo 数据
2. 进入导入页 → 点「一键导入示例」→「开始分析」→ 8 条评论全部出结果
3. 或粘贴验收用例（5 条自由职业者评论）→ 应全部识别为痛点并归入「自由职业者客户沟通与项目管理」
4. 回首页 → 今日分析数/痛点数已更新；机会雷达 → 对应机会分数与评论数上涨
5. 点开机会卡片 → 看到全部原始评论与逐条分析 → 生成研究报告
6. 刷新浏览器 → 数据仍在；「重置 Demo 数据」→ 恢复初始状态
