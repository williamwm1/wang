# NEON VELOCITY · 霓虹光速

一个 **单文件、零依赖、零素材** 的 3D 极速穿梭游戏。

打开 `neon-velocity.html` 即可游玩（双击本地打开，或任意静态服务器托管）。

## 技术亮点

整个游戏只有一个 HTML 文件，没有引用任何游戏引擎、第三方库、图片、模型或音频文件：

- **手写 WebGL2 渲染管线**：自研 4×4 矩阵库、着色器、帧缓冲后处理链
  （亮度提取 → 双向高斯模糊 → Bloom 泛光合成 → 色差 / 扫描线 / 暗角 / 胶片噪点）
- **程序化世界**：顶点着色器实时生成合成波山脉（value noise）、发光网格地面、
  复古条纹落日、闪烁星空；无尽赛道上的障碍阵型全部由算法编排
- **实时合成配乐**：WebAudio 手写合成器 —— 底鼓 / 军鼓 / 踩镲 / 锯齿波贝斯 /
  琶音器 / 失谐 Pad + 回声总线，一首完整的 108 BPM Synthwave 循环曲，
  外加穿环 / 撞击 / 爆炸 / 擦身等全部音效，全部由代码生成
- **游戏系统**：连击与狂暴模式（×2 得分、滤波器全开、画面增辉）、护盾与无敌帧、
  擦身而过奖励、慢动作死亡镜头、本地最高分、标题界面 AI 自动驾驶演示
- **全平台操控**：鼠标 / WASD / 方向键 / 手机触屏拖动

## 玩法

- 穿过 **金环** 得分并加速，连击越高分越多；连击 ×8 触发 **狂暴模式**
- 躲开霓虹柱、闸门、横杠和会移动的绿色柱子；撞击损失护盾（共 3 格）
- `Esc` 暂停

## 调试参数

- `?autostart` — 跳过标题直接开局
- `?autostart&ff=30` — AI 代打快进 30 秒（用于截图/测试）
