# AI 开发黑话翻译手册 · 第二册

## 主题：AI 开发与部署

> 共 94 个术语。翻译逻辑：程序员语言 → 普通人语言 → AI 能执行的开发需求语言。


---

## 01. 前端 · Frontend

- **分类**：开发
- **一句话理解**：用户能看见、能点的那一面。
- **生活中的例子**：餐厅里客人坐的用餐区，看得见摸得着。
- **程序员真正想表达什么**：浏览器里负责界面和交互的部分。
- **AI 会翻译成什么开发需求**：用 HTML/CSS 和 React 等做出用户可见的界面。
- **什么时候需要**：任何有界面的产品。
- **什么时候不需要**：纯后台脚本、无界面时。
- **没有它会怎样**：用户没有能看能操作的界面。
- **小白应该怎么告诉 AI**：帮我做前端界面，展示__、让用户能点__。
- **一句记忆口诀**：前端，是用户看见的那半边。

## 02. 后端 · Backend

- **分类**：开发
- **一句话理解**：藏在背后、干真正逻辑活儿的那一面。
- **生活中的例子**：餐厅后厨，客人看不见，饭菜都在这做。
- **程序员真正想表达什么**：负责数据处理、业务逻辑的服务器程序。
- **AI 会翻译成什么开发需求**：写服务器代码处理数据、规则和存储。
- **什么时候需要**：涉及数据保存、账号、计算逻辑时。
- **什么时候不需要**：纯静态展示、无逻辑时。
- **没有它会怎样**：界面是空壳，点了没有任何真实结果。
- **小白应该怎么告诉 AI**：帮我做后端，负责处理__并把数据存起来。
- **一句记忆口诀**：后端，是幕后干活的那半边。

## 19. 缓存 · Cache

- **分类**：数据
- **一句话理解**：把常用结果先存一份，下次直接拿，省得重算。
- **生活中的例子**：常用的电话记在便签上，不用每次翻通讯录。

- **什么时候不需要**：数据每次都变、缓存没意义时。
- **没有它会怎样**：每次都重算重查，系统又慢又累。
- **小白应该怎么告诉 AI**：帮我给__加缓存，重复访问时更快。
- **一句记忆口诀**：常用的先存着，下次直接拿。
