# 版式规范 · Layout Spec
《AI 开发黑话翻译手册》

定义每一类页面的结构与排版规则，供 HTML/CSS 实现与后续维护参考。

---

## 1. 页面类型

| 类型 | 说明 | 分页 |
|------|------|------|
| 封面页 cover | 书名、册名、副标题、几何图形 | 独立整页 |
| 版权页 copyright | 版本、许可、作者、免责 | 独立整页 |
| 使用说明 how-to-use | 如何阅读本书、术语页图解 | 1 页 |
| 目录 toc | 列出全部术语与页码 | 1–2 页 |
| 术语正文 term | 每词一页 | 每页一词 |
| 索引 index | 中英文术语 + 页码 | 1–2 页 |
| 后记 afterword | 结语、维护说明 | 1 页 |

页面尺寸：A4 纵向。每页 `page-break-after: always`。

## 2. 术语正文页结构（核心）

自上而下固定顺序：

```
┌────────────────────────────────────────┐
│ ▔▔▔▔ 顶部分类色条（6px，分类主色） ▔▔▔▔ │
│                                          │
│                         [ 分类标签 ▸右上 ]│
│                                          │
│   数据库                    ← 主标题 40pt │
│   Database                  ← 副标题 16pt │
│                                          │
│  ┌───────────────────────────────────┐  │
│  │ 🗄️  一句话理解                     │  │  ← 核心解释卡（浅色背景 + 左色边）
│  │ 你希望下次打开时，之前的内容还在。 │  │     22pt，最醒目
│  └───────────────────────────────────┘  │
│                                          │
│  ● 生活中的例子                          │  ← 浅色卡片
│    微信聊天记录不会因为关掉就消失。      │
│                                          │
│  ● 程序员真正想表达什么                  │
│  ● AI 会翻译成什么开发需求               │
│                                          │
│  ┌── 什么时候需要 ──┐ ┌ 什么时候不需要 ┐│  ← 双列小卡
│  └──────────────────┘ └────────────────┘│
│                                          │
│  ● 没有它会怎样                          │
│  ● 小白应该怎么告诉 AI（可复制句）       │  ← mono 引用块
│                                          │
│   〝 一句记忆口诀 〞          ← 居中斜体  │
│                                          │
│  册名 · 分类                     0 4 2 页 │  ← 页脚
└────────────────────────────────────────┘
```

### 模块清单（顺序固定）
1. 顶部分类色条
2. 分类标签（右上角胶囊）
3. 主标题（中文术语）
4. 副标题（英文术语）
5. 核心解释卡：**一句话理解**（页面焦点）
6. 生活中的例子
7. 程序员真正想表达什么
8. AI 会翻译成什么开发需求
9. 双列：什么时候需要 / 什么时候不需要
10. 没有它会怎样
11. 小白应该怎么告诉 AI（可直接复制的一句话，mono 引用块）
12. 一句记忆口诀（居中）
13. 页脚：册名 · 分类 · 页码

---

## 3. 排版规则

- 主标题与副标题左对齐，紧贴。
- 核心解释卡是唯一使用大字号（22pt）正文的模块，视觉权重最高。
- 模块小标题前加一个 6px 分类色圆点。
- 「什么时候需要 / 不需要」用两列并排，节省纵向空间。
- 「告诉 AI」用 mono 字体 + 浅色引用块，提示「可复制」。
- 记忆口诀居中，前后加书名号「〝〞」，与正文拉开距离。
- 若单页内容偏多：优先缩短文字，保持清楚；绝不缩小到看不清或溢出。

---

## 4. 目录与索引

- **目录**：按正文顺序列「序号 · 中文术语 · 英文 · 页码」，点线连接。
- **索引**：分「按中文」与「按英文（A–Z）」两栏，各带页码。
- **总索引**（05_Index/all_terms_index.md）：中文 / 英文 / 所属册 / 分类 / 页码。

---

## 5. 页码规则

- 封面、版权页不计页码。
- 使用说明起页码 = 1（用于内部导航），正文术语页显示实际页码。
- 页脚右下角显示页码，左下角显示「册名 · 分类」。
