# 设计系统 · Design System
《AI 开发黑话翻译手册》

本文件定义整套手册的视觉语言。三册共用同一套设计系统，保证风格统一、可长期维护。

参考气质：Apple 产品手册的克制、MUJI 说明书的朴素、Notion 知识库的清晰、高级电子书的呼吸感。
一句话原则：**留白比内容多，字大比字多好，一页只讲一件事。**

---

## 1. 设计原则

1. **一页一词** —— 每个术语独占一页，绝不拥挤。
2. **一眼看懂** —— 「一句话理解」是整页最醒目的元素。
3. **大量留白** —— 页边距大、行距松、模块之间留呼吸空间。
4. **克制用色** —— 每页最多 2–3 个强调色，其余全部是米白、灰、黑。
5. **不用黑话解释黑话** —— 所有文字都写给完全不懂技术的人。
6. **结构稳定** —— 每页模块顺序固定，读者可预期。

## 2. 色彩系统

### 2.1 中性色（页面主体）

| 名称 | 色值 | 用途 |
|------|------|------|
| 背景米白 | `#F7F3EA` | 页面外底色 |
| 纸张白 | `#FFFDF8` | 卡片 / 正文纸面 |
| 正文黑 | `#1F1F1F` | 主要文字 |
| 中灰 | `#6F6F6F` | 副标题、英文、辅助文字 |
| 浅灰 | `#E8E3D8` | 分隔线、边框、留白块 |

### 2.2 强调色（按分类）

每个分类绑定一个强调色 + 一个浅色背景，用于分类标签、色条、卡片底色。

| 分类 | 强调色 | 浅色背景 |
|------|--------|----------|
| 产品 / 商业 | 橙 `#D9822B` | `#F8EFE4` |
| 开发 | 蓝 `#3A6EA5` | `#EAF2F8` |
| 部署 / 安全 | 绿 `#5F8D4E` | `#EDF5EA` |
| AI / GitHub | 紫 `#7A5C99` | `#F1ECF6` |
| 数据 | 蓝 `#3A6EA5` | `#EAF2F8` |

> 规则：一页里主色只用于「分类标签 + 顶部色条 + 核心解释卡左边线」，浅色背景只用于核心解释卡与生活例子卡。其余保持中性。

## 3. 字体系统

- **中文正文 / 标题**：Noto Sans CJK SC（等价 PingFang SC / Source Han Sans SC）
- **英文 / 数字**：Inter（等价 Helvetica Neue）
- **代码 / 技术英文词**：DejaVu Sans Mono（等价 JetBrains Mono / SF Mono）
- 全部无衬线。**禁止**宋体、Times New Roman、花体、浏览器默认字体。

字体栈（CSS）：
```
--font-sans: "Inter", "Noto Sans CJK SC", "PingFang SC", "Source Han Sans SC", sans-serif;
--font-mono: "DejaVu Sans Mono", "JetBrains Mono", "SF Mono", monospace;
```

## 4. 字号阶梯（Type Scale）

| 角色 | 字号 | 字重 | 说明 |
|------|------|------|------|
| 术语主标题（中文） | 40 pt | 700 | 每页最大，醒目 |
| 术语副标题（英文） | 16 pt | 500 | 中灰，字距略宽 |
| 分类标签 | 12 pt | 600 | 右上角胶囊 |
| 核心解释「一句话理解」 | 22 pt | 600 | 页面焦点，浅色卡片内 |
| 模块小标题 | 13 pt | 700 | 带色点 |
| 模块正文 | 15 pt | 400 | 行距 1.7 |
| 记忆口诀 | 17 pt | 600 | 斜体感、居中 |
| 页脚 / 页码 | 10 pt | 400 | 中灰 |

## 5. 图标系统

线性、低饱和、简洁。用 emoji + CSS 图形组合，保持高级、不廉价卡通。
每个术语可绑定一个代表性 emoji 图标，放在核心解释卡旁。示例约定：

| 概念 | 图标意象 |
|------|----------|
| 数据库 | 🗄️ 仓库 / 抽屉 |
| 部署 | 🚀 火箭 / 🌐 上线 |
| API | 🔌 插头 / ☎️ 传话 |
| 服务器 | 🖥️ 机柜 |
| GitHub | 📚 代码图书馆 |
| Agent | 🤖 小助手 |
| Skill | 🧰 工具箱 |
| 网页 | 📄 一张纸 |
| 网站 | 🏢 一栋楼 |

## 6. 间距与栅格

- 页面：A4 纵向（210 × 297 mm）
- 页边距：上 20mm / 下 18mm / 左右 22mm
- 模块间距：18–22px
- 卡片圆角：14px；卡片内边距：20–24px
- 色条：顶部 6px 满宽，取分类主色

---

## 7. 禁止清单

- ❌ 黑色科技风、霓虹渐变
- ❌ 五颜六色（超过 3 个强调色）
- ❌ 密密麻麻、教材式排版
- ❌ Word 默认样式
- ❌ 用黑话解释黑话
- ❌ 「待完善」「TODO」「空模板」
